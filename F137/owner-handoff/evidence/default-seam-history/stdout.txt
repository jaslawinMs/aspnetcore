    Include parameter default value in RDG endpoint comparison (#69752)
    
    Endpoints whose handlers differ only by a parameter's default value (for example (int page = 1) and (int page = 2)) were treated as equal and grouped under a single interceptor. The interceptor casts the handler to the first endpoint's delegate type, so the second endpoint threw an InvalidCastException at startup.
    
    Compare HasDefaultValue and DefaultValue in EndpointParameter.Equals and GetHashCode so these endpoints get separate interceptors.
    
    Fixes #69675
